# CIST Integration Service

치매선별검사(CIST)를 자연스러운 대화에 통합하는 서비스

## 개요

기존 사진 기반 대화 시스템에 CIST(Cognitive Impairment Screening Test) 문항을 자연스럽게 녹여내어 인지기능을 평가하는 시스템입니다.

## CIST 검사 영역

### 음성 대화 가능한 평가 영역

1. **지남력 (5점)**

    - 시간 지남력(4점): 오늘 날짜 (연, 월, 일, 요일)
    - 장소 지남력(1점): 현재 계신 장소

2. **기억력 (10점)**

    - 기억등록: 문장 바로 따라하기
    - 기억회상: 이전 문장 다시 말하기
    - 기억재인: 회상하지 못한 항목 재인

3. **주의력 (1점)**

    - 숫자나 단어 거꾸로 말하기

4. **집행기능 (2점)**

    - 언어추론: 과일/채소 등 일반적인 카테고리의 단어 생성

5. **언어기능 (3점)**
    - 이름대기: 이미지 기반 사물 이름 말하기 (사진 대화 시 자연스럽게)

### 제외되는 평가 영역

-   주의력 중 숫자 바로 따라 말하기: 대화의 자연스러움을 해칠 가능성 존재
-   시공간기능 중 도형모사: 터치 입력 없음
-   집행기능 중 시각추론: 복잡한 시각 자료 필요
-   언어기능 중 이해력: 사용자의 행동을 평가할 수 없음

## 아키텍처

-   LangChain/LangGraph 기반 대화 흐름 관리
-   기존 FastAPI 시스템과 통합
-   실시간 평가 및 점수 계산

## 총 평가 가능 점수: 21점 (30점 만점 중)
